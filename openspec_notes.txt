claude:
  Default path vs Expanded path — what they actually are

  Both are OPSX. The distinction isn't legacy vs. new. It's granularity of control.

  Default quick path (core profile):
  /opsx:propose ──► /opsx:apply ──► /opsx:sync ──► /opsx:archive

  Expanded path (custom workflow selection):
  /opsx:new ──► /opsx:ff or /opsx:continue ──► /opsx:apply ──► /opsx:verify ──► /opsx:archive

  The actual legacy is something else entirely — the original OpenSpec workflow where instructions were hardcoded in TypeScript, locked,
  all-or-nothing, no customization. OPSX replaced that entirely. When the docs say "OPSX is now the standard workflow for OpenSpec," they mean OPSX
  superseded that old TypeScript system.

  Yes.The schema extensibility (schema.yaml + user-editable templates) is specifically what OPSX introduced over the legacy workflow. The legacy
  system had hardcoded prompts you couldn't touch. OPSX is the one where you can edit templates and have changes take effect immediately at runtime —
  which is exactly what our research confirmed (finding 1.4, confidence 2-1).
  Use the expanded path. Three reasons specific to your ticket:

  1. AC#2 (versioned artifacts against a schema) — the expanded path makes each artifact explicit and separable. You can point to new → ff → apply →
  verify as distinct phase outputs. With the default, it all collapses into one propose step which is harder to demonstrate as "each phase produces a
  versioned artifact."
  2. AC#3 (plugs into different targets without forking) — the expanded path exposes the template/schema layer more directly. When you customize for
  Solo vs. Team vs. Scale, you're editing the templates that ff/continue uses. This is the customization story for your demo.
  3. Learning — you're new to OpenSpec. The expanded path shows you what's happening at each step. The default path is a black box on first run.

  For the two-feature PoC, you could run feature 1 with the default path (to understand the baseline) and feature 2 with the expanded path (to show the
  customization angle). That contrast also makes good article material.
